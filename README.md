# 风险评估与反例库（Web3 防骗工具箱）

> 本技能由《价值互联网产业应用蓝皮书（2025）》经 cangjie-distill 蒸馏流水线提取编排，帮助普通用户识别真假 Web3、厘清合规边界、避开资金盘陷阱。

## 功能简介
对 RWA/Web3 项目做产业/产品/合规三层体检，并嵌入三大爆雷反例（伪 RWA、责任真空、慢资产快金融）作边界警示。
  当用户在立项前、投资前或审计一个"上链/通证化/RWA"项目时激活：①想识别"伪 RWA""慢资产快金融""责任真空"等结构性风险；②面对"高收益稳定、上链即安全""回款慢却承诺 T+0 流动性"等话术；③尽调资产自偿性、SPV 破产隔离、预言机责任边界是否到位。
  不适用于：纯境内概念澄清（转 S1）、纯合规生死判读（转 S2）、纯 RWA 落地路径设计（转 S8）。

## 安装方式

### 方式一：从 ClawHub 一键安装（推荐）
在 ClawHub 搜索 `risk-assessment-antipattern`，或用 CLI：
```bash
clawhub skill install risk-assessment-antipattern
```

### 方式二：从 GitHub 安装
```bash
git clone https://github.com/63619990/risk-assessment-antipattern.git
cp -r risk-assessment-antipattern/ ~/.workbuddy/skills/
```
重启 WorkBuddy 后，对话出现相关信号即自动激活。

### 方式三：手动安装
将本仓库 `risk-assessment-antipattern/` 目录整体复制到 `~/.workbuddy/skills/`（Windows 为 `%USERPROFILE%\.workbuddy\skills\`）。
